# ✈️ JourneyAI — Multi-Agent AI Travel Planner

JourneyAI is an AI-powered multi-agent travel planning system that helps users create personalized travel itineraries based on their destination, budget, duration, interests, and travel preferences.

Instead of relying on a single LLM call, JourneyAI uses multiple specialized AI agents that collaborate to handle different aspects of trip planning and generate a structured travel plan.

---

## 🚀 Features

- 🤖 Multi-Agent AI Architecture
- 🗺️ Personalized travel itinerary generation
- 📍 Destination and activity recommendations
- 💰 Budget-aware trip planning
- 🏨 Accommodation suggestions
- 🍴 Food and restaurant recommendations
- 📅 Day-by-day itinerary generation
- 🎯 Preference-based recommendations
- 💬 Natural-language interaction
- 🌐 Web-based interface
- ⚡ AI-powered response generation
